What I got wrong the first time, and what's actually there

Typography — corrected
Not a terminal font. It's a plain serif (Times/Georgia-class) for all running text, with bold serif used for category labels — the "default browser stylesheet" look, not a styled UI. I've substituted IBM Plex Serif here.
Color — corrected
Black text on plain white, with links left in classic browser blue/purple (#1237c4 / #63239e) rather than a designed accent — that's what reads as "early internet": nothing was restyled away from the default.
Layout — corrected
Three plain columns, no borders, no nav bar, no chrome: bio/skills, a reverse-chronological project list (year + linked title + italic one-liner), then the large ASCII illustration filling the right side. A tiny italic status label sits top-right.
The ASCII art — still holds
The JS bundle still confirms a .glb model run through Three.js's AsciiEffect with a density-character ramp and a dedicated DOS-codepage font for the character glyphs specifically — that part of my read was right, it's just rendered in plain black-on-white here, not a colored terminal panel.
